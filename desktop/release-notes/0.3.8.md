## Teachshell 0.3.8

课程、课件与计划管理的 Electron 桌面版，支持离线管理本地资料。

### 下载

- Windows x64：`Teachshell-0.3.8-win-x64.exe`，可选择安装目录的安装程序。
- macOS Apple Silicon（M 系列）：`Teachshell-0.3.8-mac-arm64.dmg` 或 `.zip`。
- macOS Intel：`Teachshell-0.3.8-mac-x64.dmg` 或 `.zip`。
- `SHA256SUMS.txt` 提供安装包摘要，`release-manifest.json` 记录版本、源提交与包校验结果。

### 更新

- 修复 Windows 文件导入和事务提交的磁盘刷新兼容性，保留只读源文件与权限。

- 月、周、日计划视图统一日期、筛选和侧栏。
- 课程详情支持每周时段、单次调课、未定时课程排课、颜色继承、关联资料和作业。
- 新增课表撤销、待安排默认新建、全天安排及空白时间轴拖动创建。
- 保留 Swift JSON 数据兼容、真实课件目录、AI/MCP 和教学网站同步功能。

Teachshell 使用独立应用标识，不替换原生「课屿」。导入或复制资料库后使用，不支持两款应用同时修改同一资料库。

macOS 使用 ad-hoc 签名并验证完整性，尚未通过 Apple Developer 签名/公证；Windows 安装包尚无 Authenticode 发布者签名。操作系统可能显示未验证发布者提示。真实教学网站登录仍取决于校园网络和账号环境。
