## Teachshell 0.3.12

### 本次更新

- 改善按钮反馈：按下态立即显示；刷新按实际操作完成状态恢复，不再等待装饰动画。设置、启动配置、作业列表及资料预览读取不再锁住无关顶栏与搜索操作。
- 修复键盘事件冲突：资料快捷键不再抢占按钮或菜单；收藏按钮按 Enter 不再意外打开文件；计划调时只作用于焦点所在的事件卡片或边界。
- 修复丢弃未保存资料修改后第一次点击失效的问题，保留拖动、取消和未保存草稿保护。
- 将慢作业目录枚举移出仓库写入队列，返回前复核目录身份、挂载位置和工作区；更换选择或页面后忽略迟到的预览结果。
- 减少同步中的重复文件检查和全量身份匹配，改善大资料库收藏等操作的响应；保留提交后的路径、文件身份及硬链接歧义检查。
- 修复 macOS 连续目录改名后的监听丢事件，覆盖课程移动、资料改名、目录替换和切换资料库后的自动同步。

### 验证与兼容性

- 修复版本在本机 macOS Apple Silicon 已通过 346 项业务测试、24 组源码窗口回归及 22 组安装版窗口回归；发布流水线另外在 Windows x64 和 macOS ARM64 原生 runner 上执行业务测试、完整源码窗口回归、包结构/架构校验和打包应用专项。
- 保留现有资料库 JSON 格式、课程资料、教学网站入口与登录设置。原生「课屿」应用及资料保持独立，不会被替换或修改。
- 慢目录的准备与路径校验仍受仓库队列保护；此次没有取消系统层正在等待的 IO。响应速度仍受磁盘和资料库规模影响。

### 下载

- Windows x64：`Teachshell-0.3.12-win-x64.exe`，可选择安装目录。
- macOS Apple Silicon（M 系列／ARM64）：`Teachshell-0.3.12-mac-arm64.dmg` 或 `.zip`。不支持 Intel Mac，不提供 Intel 或 Universal 安装包。
- `SHA256SUMS.txt` 提供安装包摘要；`release-manifest.json` 记录平台、版本、源提交和包校验结果。

macOS 安装包使用 ad-hoc 签名并验证完整性，尚未通过 Apple Developer 签名／公证；Windows 安装包尚无 Authenticode 发布者签名。
