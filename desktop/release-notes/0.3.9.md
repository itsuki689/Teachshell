## Teachshell 0.3.9

### 本次更新

- 右上角刷新现在重新读取当前页面的本地数据，不再打开教学网站更新。未连接网站、离线时也可使用。
- 刷新保留所在课程、作业子目录、月／周／日视图的日期与筛选，以及聊天输入；设置中的未保存修改仍需确认后才丢弃。
- 修复刷新等待期间的重复点击处理，失败时显示错误并可重试；动画不再延迟实际刷新。
- 加号菜单移除 Moodle／教学网站入口，只保留新建课程和计划。已有网站工具及状态栏待审核入口继续可用。
- Windows 和 macOS 打包后的验收新增本次页面刷新和顶栏交互测试。

### 下载

- Windows x64：`Teachshell-0.3.9-win-x64.exe`，可选择安装目录。
- macOS Apple Silicon（M 系列）：`Teachshell-0.3.9-mac-arm64.dmg` 或 `.zip`。
- macOS Intel：`Teachshell-0.3.9-mac-x64.dmg` 或 `.zip`。
- `SHA256SUMS.txt` 提供安装包摘要；`release-manifest.json` 记录各平台版本、源提交和包校验结果。

此版本使用独立的 Teachshell 应用标识和本地服务，保留原生「课屿」，不替换或修改它。旧版 Teachshell 资料库可继续使用；原生资料请通过复制导入迁移。

macOS 安装包使用 ad-hoc 签名并验证完整性，尚未通过 Apple Developer 签名／公证；Windows 安装包尚无 Authenticode 发布者签名，系统可能提示未验证发布者。
