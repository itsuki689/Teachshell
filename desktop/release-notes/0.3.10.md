## Teachshell 0.3.10

### 本次更新

- 恢复右上角加号菜单中的“连接教学网站…”入口，可进入现有网站登录、课程连接、资料导入及更新审核工具。
- 恢复网站入口的地球图标和键盘菜单导航；打开入口前继续保护未保存的设置，取消时保留草稿。
- 右上角刷新继续刷新当前页面的本地数据，保留课程、月／周／日日期和筛选、作业目录及聊天输入，离线也可使用。
- 从此版本开始，macOS 仅支持 Apple Silicon（M 系列／ARM64），停止提供 Intel Mac 安装包；构建与发布校验会拒绝 Intel 或 Universal Mac 目标。

### 下载

- Windows x64：`Teachshell-0.3.10-win-x64.exe`，可选择安装目录。
- macOS Apple Silicon：`Teachshell-0.3.10-mac-arm64.dmg` 或 `.zip`。
- `SHA256SUMS.txt` 提供安装包摘要；`release-manifest.json` 记录平台、版本、源提交和包校验结果。

新版 Teachshell 可继续使用现有资料库。原生「课屿」应用与资料保持独立，不会被替换或修改。

macOS 安装包使用 ad-hoc 签名并验证完整性，尚未通过 Apple Developer 签名／公证；Windows 安装包尚无 Authenticode 发布者签名，系统可能提示未验证发布者。
