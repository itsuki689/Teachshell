## Teachshell 0.3.11

### 本次更新

- 修复 Windows 回归中发现的教学网站登录记忆并发问题：页面解析期间暂停登录设置操作，保存登录偏好期间暂停其他网站操作，避免请求重叠被拒绝。
- 登录设置请求被拒绝时，复选框恢复为实际状态并显示错误，避免界面已勾选但偏好未保存。
- 加强登录回归，验证真实系统加密存储、重启恢复、关闭记忆后的清除，以及保存期间正常退出；发布前同时验证源码版和打包版。
- 修正拖拽调课和登录状态测试的等待逻辑，等待已提交结果渲染及实际 IPC 状态满足条件后再断言。
- 保留教学网站入口、本地页面刷新、资料库格式和现有课程资料。

### 下载

- Windows x64：`Teachshell-0.3.11-win-x64.exe`，可选择安装目录。
- macOS Apple Silicon（M 系列／ARM64）：`Teachshell-0.3.11-mac-arm64.dmg` 或 `.zip`。不支持 Intel Mac，不提供 Intel 或 Universal 安装包。
- `SHA256SUMS.txt` 提供安装包摘要；`release-manifest.json` 记录平台、版本、源提交和包校验结果。

新版 Teachshell 可继续使用现有资料库。原生「课屿」应用与资料保持独立，不会被替换或修改。

macOS 安装包使用 ad-hoc 签名并验证完整性，尚未通过 Apple Developer 签名／公证；Windows 安装包尚无 Authenticode 发布者签名，系统可能提示未验证发布者。
