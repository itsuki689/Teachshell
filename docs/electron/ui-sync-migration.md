# 界面状态与原生交互同步

2026-10-28 增补：`workspace-sync.e2e.mjs` 实际移动课程及已登记课件，不点击刷新，核对侧栏/资料更新、后续改名和切库后新监听生效。监听注册完成后补一次扫描；旧库回调仍受 Repository 身份、切库和退出守卫约束。见[监听实现与回归](filesystem-watch.md)。

本轮对照实际 Swift 实现并在 Electron 窗口复现后修复，不改变 Swift 文件或资料库 JSON 格式。

## 异步状态约束

- 资料快捷键仅由资料画布处理，忽略已处理事件、输入法组合及行内按钮；列表 Enter 只在行本身有焦点时打开文件。Space 不抢占顶栏/菜单/收藏控件。计划调时键绑定事件卡片及边界控件，离开事件后不能意外调课；跨天重建和保存后只在用户未另行移焦时恢复原焦点。
- 拖动预检查可能在 pointerdown 弹出草稿确认；记录原始指针的短距离点击，确认丢弃后继续原选择。超过拖动阈值、取消或失焦不能被后续确认按钮的 pointerup 误当作资料单击。仍不在 pointerdown 改变选择栏布局。
- 只读加载与阻止重复写入分开计数：`library.read` 驱动状态栏进度，不占用 `busy`。设置初始加载及应用信息读取、作业目录列表使用它，因此慢读取不会禁用设置按钮或吞掉搜索/设置快捷键。尚未加载的设置字段继续禁用；保存、同步、切库和未保存草稿确认保持原有保护。
- 应用启动/聊天配置读取也使用 `read`，较晚的初始设置不覆盖已加载或已保存的配置。资料预览读取不锁住选择和顶栏；相同待处理预览去重，更换选择、离开页面或切库会使旧结果/错误失效。
- 作业目录在 Repository 队列内准备并记录目录身份，实际枚举在队列外执行。返回前再次检查 Repository、课程位置/挂载映射、目录身份及符号链接祖先。慢旧枚举不能阻挡新目录读取或无关写入；目录准备、挂载校验与前置同步仍受串行队列保护，没有取消系统层正在等待的 IO。
- Repository 同步用本次安全扫描的 Entry 构建身份索引并保存 observations，避免对每个索引条目重复遍历全部 Entry 和重复 stat。精确路径优先、硬链接歧义、缺失身份和原位替换语义保留；应用写入后仍重新执行路径与文件身份校验，不复用写入前快照。
- 页面读取携带存活状态、请求代次及资料库身份约束；已退出页面或被后续请求替代的结果和错误均不能写回状态。刷新按钮只等待实际业务完成，不等待 400 ms 装饰动画；动画被暂停时也不能持续锁住按钮，实际同步未完成时仍阻止重复操作。
- 按钮按下态不参与通用 120 ms 颜色过渡，鼠标按下和空格键按下立即显示反馈，悬停与松开过渡保留。只调整视觉反馈，不提前执行 `click`：拖出按钮再松手仍取消操作，空格键松开时才执行一次。该样式为跨平台共用，Windows 原生执行结果须以 Windows runner 或实机为准。
- Repository 为每次打开分配 `workspaceID`，为创建的每份 IPC 快照分配单调 `sequence`。两者不写入 `library.json`，也不改变数据 revision。旧回复不能倒退界面，新创建对象及编辑基线仍从该操作自己的返回快照读取。
- 主进程拒绝切库前操作的迟到返回，预览、打开资料、备份及文件监听绑定原 Repository。切库会关闭旧编辑器、取消确认、清空导航并重建页面；菜单与快捷键遵循相同的未保存保护及模态边界。
- 资料详情保存期间允许继续输入。完成时只刷新未继续编辑的字段；继续编辑字段保留其已知基线，其他操作修改同字段后再次保存会报告冲突。关闭、换选择或拖动不会静默丢弃草稿。
- 作业页读取新课程时立即移除旧行，编辑操作捕获原课程和目录；旧页面不会在切库卸载期间向新库请求旧课程。聊天读取使用请求代次，清空后迟到历史不能重新显示已删除消息。
- 网站请求绑定类型、资料库和请求代次。单项预览以响应式时钟判断有效期，登录失效或换账号会锁定旧结果，重新读取后才能预览。登录和巡检设置的初始读取不能覆盖较新的事件。

## 回归方式

`npm test` 包括真实 Repository 快照顺序、迟到请求、导航保护、搜索与范围选择测试。

`node tests/input-response.e2e.mjs` 专门验收按键响应：暂停真实刷新动画但完成真实同步，确认按钮立即可再次按键；延迟设置与作业列表的实际 IPC 回复，确认搜索输入、设置快捷键和返回按钮可用；同时核对同步未完成时的防重复保护。测试使用事件屏障，避免依赖固定毫秒阈值或放宽超时；纳入 `npm run test:e2e` 和安装版相同入口。

另外检查真实鼠标、空格键按住时的可见按下态没有未完成的颜色过渡，并核对拖出取消和松键触发。报告记录实际运行平台，不能把 macOS 结果当作 Windows 已验证。

`keyboard-routing.e2e.mjs` 使用实际选中的临时文件验收按钮、菜单、收藏与资料列表/封面的键盘归属；`schedule-drag.e2e.mjs` 覆盖事件外焦点不调课和连续调时；`e2e-ui-parity.mjs` 覆盖确认丢弃后第一次点击选择。`input-response` 另外延迟启动设置和预览的真实 IPC 回复，检查导航、选择和迟到结果隔离。`homework.test.ts` 直接阻塞真实目录的 readdir，验证队列独立与挂载/目录/切库竞态；`repository.test.ts` 用实际扫描计数验证复杂度，不以固定耗时阈值判定性能。

`npm run test:e2e` 现在额外运行 `workspace-sync.e2e.mjs`、`e2e-component-sync.mjs`、`e2e-ui-parity.mjs`、`website-context.e2e.mjs`。这些测试启动真实 Electron 主窗口、preload 与主进程，使用临时资料库。竞态用延迟真实 IPC 返回暴露；学校页面和 AI 服务使用受控夹具，不读取真实账号。界面验收覆盖 1260×800、最小 1020×680、浅色/深色、实际键盘与拖动。

设置 `TEACHSHELF_EXECUTABLE=/Applications/Teachshell.app/Contents/MacOS/Teachshell` 可对实际安装版运行相同测试。安装仅更新 Teachshell；原生课屿保留。实际结果、截图及安装限制见 [验证报告](validation.md)。
